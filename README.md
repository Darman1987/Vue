# Vue.js Practice Repository

This repository contains basic Vue.js practice examples structured by different branches. Each branch demonstrates a specific Vue.js concept or feature, making it easy to learn and reference specific functionality.

---

## 📁 Branches Overview

| Branch Name         | Description                                                                 |
|---------------------|-----------------------------------------------------------------------------|
| `basic` *(default)* | Basic Vue.js setup with template syntax, data binding, and simple logic.    |
| `events`            | Demonstrates Vue.js event handling (`v-on`) with methods.                   |
| `for`               | Showcases rendering lists with `v-for` and basic key usage.                 |
| `img-url-class`     | Covers binding image sources (`v-bind:src`) and dynamic CSS classes.        |
| `computed`          | Illustrates the use of computed properties for reactive data transformations.|

---

## 🏷️ Tags

Tags are applied to track specific milestones and concepts for each branch. For example:

- `v1.0-basic`
- `v1.1-events`
- `v1.2-for`
- `v1.3-img-url-class`
- `v1.4-computed`
